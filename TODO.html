Toolchain & Bootloader (Multiboot2 / Limine)
0/6 concluídos
Configuração da Toolchain Cross-Compiler x86_64 Boot
Configurar x86_64-elf-gcc ou Clang com flags sem dependência de libc (-ffreestanding -mno-red-zone -mno-mmx -mno-sse -fno-pie).
Flags: -O2 -march=bonnell -mtune=bonnell -mno-red-zone -mcmodel=kernel
Cabeçalho Multiboot2 & Linker Script Boot
Definir o cabeçalho Multiboot2 (magic 0xE85250D6) e criar o linker.ld mapeando o kernel na metade superior (Higher-Half) em 0xFFFFFFFF80000000.
Tags: Information Request (Framebuffer, Memory Map, ACPI RSDP)
Ponto de Entrada em Assembly (entry.asm / boot.S) Boot
Receber o controle em 32-bit Protected Mode, verificar CPUID, habilitar PAE (CR4.PAE = 1), carregar tabelas de página de inicialização e entrar em 64-bit Long Mode (EFER.LME = 1, CR0.PG = 1).
Instruções: lgdt, mov cr4, mov cr3, wrmsr 0xC0000080, mov cr0
Console de Depuração Primitivo (VGA / Porta Serial COM1) Driver
Implementar driver de saída serial RS-232 na porta 0x3F8 (COM1, 115200 8N1) para logs imediatos e saída básica no Framebuffer VGA texto (0xB8000).
I/O Ports: outb(0x3F8, ch) - Compatível com QEMU e netbooks reais
Geração de Imagem ISO Bootável (GRUB2 / Limine) Boot
Script para empacotar o kernel binário em uma imagem ISO inicializável tanto via BIOS Legado quanto via UEFI usando grub-mkrescue ou Limine.
Target: atom_os.iso para boot em pendrive USB ou QEMU (-cdrom)

Núcleo da Arquitetura x86-64 & Intel Atom
0/6 concluídos
GDT (Global Descriptor Table) de 64 bits & TSS Core
Definir GDT definitiva com segmentos de Kernel Code/Data (DPL 0), User Code/Data (DPL 3) e Task State Segment (TSS) com RSP0 e IST para interrupções seguras.
Estruturas: gdt_entry_t, tss_entry_t, lgdt, ltr
IDT (Interrupt Descriptor Table) & Rotinas ISR/IRQ Core
Configurar 256 vetores de interrupção (0..31 para exceções do processador como #GP, #PF, #DF, e 32..255 para hardware IRQs).
Registradores: lidt, pushaq/popaq, iretq, IST1 (Double Fault)
Identificação de CPUID do Intel Atom Bonnell Atom N450
Detectar Family 6, Model 28 (Pineview N450), checar suporte a EM64T, SSSE3, Hyper-Threading, VMX (não suportado no N450), e topologia de cache L1/L2.
CPUID: EAX=1 (Stepping/Family), EAX=4 (Topologia de Caches)
Desativação do 8259 PIC Legado Core
Remapear e mascarar completamente os chips mestres e escravos 8259 PIC para migrar o sistema para o subsistema moderno APIC do Atom.
I/O: outb(0x21, 0xFF); outb(0xA1, 0xFF)
Local APIC & I/O APIC (Intel NM10) Atom N450
Habilitar Local APIC (MSR 0x1B, Spurious Vector 0xF0) e configurar o Intel NM10 I/O APIC em 0xFEC00000 para roteamento dinâmico de IRQs de barramento.
MSR: IA32_APIC_BASE (0x1B), APIC_SPIV (0xF0)
Temporizador HPET (High Precision Event Timer) & APIC Timer Atom N450
O Intel NM10 possui bloco HPET em 0xFED00000. Calibrar o APIC Timer usando o HPET para agendamento preemptivo estável de threads.
Registradores HPET: GCAP_ID (0x00), GEN_CONF (0x10), MAIN_CNT (0xF0)

Gerenciamento de Memória (Paging & Heap)
0/5 concluídos
PMM: Alocador Físico de Memória (Bitmap / Buddy Allocator) Memória
Analisar o mapa de memória fornecido pelo Multiboot2 (E820) e implementar alocador de páginas físicas de 4 KB (suportando até os 2 GB DDR2/DDR3 suportados pelo N450).
Algoritmo: Bitmap com busca por first-fit ou Buddy Allocator
VMM: Paginação em 4 Níveis (PML4, PDPT, PD, PT) Memória
Gerenciador de memória virtual de 64 bits. Mapeamento Higher-Half, isolamento entre páginas de Kernel e Userland, e suporte a páginas grandes de 2 MB (PDE.PS=1).
Flags: PAGE_PRESENT | PAGE_WRITE | PAGE_USER | PAGE_NX
Tratamento de Exceções de Page Fault (#PF - Vector 14) Memória
Tratar faltas de página lendo o endereço causador em CR2 e o Error Code na pilha (detectar violações de permissão vs páginas alocadas sob demanda).
Registrador: mov %cr2, %rax; Análise de bits: P, W/R, U/S, RSVD, I/D
Alocador Dinâmico do Kernel (kmalloc / kfree) Memória
Implementar Slab Allocator ou Dlmalloc para alocações arbitrárias de memória no espaço do kernel com baixa fragmentação.
Estruturas: slab_cache_t, kmalloc(size_t sz), kfree(void* ptr)

Multithreading, SMT (Hyper-Threading) & Otimizações Atom
0/5 concluídos
Context Switching Preemptivo em x86-64 Core
Salvar e restaurar registradores de uso geral (RAX-R15), ponteiro de pilha RSP, registradores de controle e ponteiro de instruções RIP acionado pelo APIC Timer.
Estrutura: context_t, switch_to(prev_thread, next_thread)
Inicialização SMP/SMT (Hyper-Threading - Thread 1) Atom N450
O N450 possui 1 Core físico e 2 Threads lógicas. Acordar a segunda thread (Application Processor) via sequência INIT-SIPI-SIPI através do Local APIC ICR.
Sequência: APIC_ICR_INIT -> udelay(10000) -> APIC_ICR_STARTUP
Otimização de Pipeline In-Order (Bonnell Microarchitecture) Atom N450
O Atom N450 executa instruções estritamente em ordem (dual-issue in-order). Otimizar rotinas críticas do kernel evitando hazards de dados e alinhando loops em limites de 16 bytes.
Técnicas: .align 16, desenrolamento de laços, evitar dependências RAW imediatas
Primitivas de Sincronização SMT-Safe Core
Implementar Spinlocks com instrução PAUSE (essencial para não travar o pipeline compartilhado entre as duas threads SMT no Atom) e Mutexes.
Assembly: rep; nop (pause), lock cmpxchgq, lock xaddq

Barramento PCI & Drivers do Chipset Intel NM10 Express
0/6 concluídos
Enumerador de Barramento PCI (PCI Bus Scan) Driver
Varredura de 256 barramentos x 32 dispositivos x 8 funções via portas 0xCF8 (CONFIG_ADDRESS) e 0xCFC (CONFIG_DATA). Detecção dos dispositivos integrados da Intel (Vendor ID 0x8086).
I/O Ports: 0xCF8 / 0xCFC, BARs (Base Address Registers), IRQ Pin/Line
Driver de Armazenamento SATA AHCI (Intel NM10 SATA) Driver
Controlador SATA AHCI 1.0 integrado no NM10 (Device ID 0x27C0 / 0x27C4). Configurar Command Lists, FIS de recepção e transferências DMA via PRDT.
Registradores AHCI: GHC (Global Host Control), Port Command/Status, PRDT
Teclado e Touchpad PS/2 (i8042 LPC Controller) Driver
Netbooks com N450 utilizam teclado e touchpad integrados conectados ao controlador SuperIO/LPC compatível com i8042 (Portas 0x60 e 0x64, IRQ 1 e IRQ 12).
I/O: Porta 0x60 (Data), 0x64 (Status/Command), Protocolo PS/2 Mouse & ScanCode Set 2
Intel GMA 3150 Graphics & Framebuffer Linear Driver
GPU integrada Intel GMA 3150 (PCI Device 0x8086:0xA001/0xA011). Inicialização em resolução nativa do netbook (1024x600) via VBE/GOP ou MMIO BAR0.
Resolução típica: 1024x600 32bpp, Renderizador de fontes Bitmap e Blitting
Rede Ethernet Realtek RTL8101E / RTL8102E / RTL8111 Driver
Placa de rede onboard predominante nos netbooks com NM10. Configurar anéis de descritores de RX/TX e interrupções PCI.
Protocolo: Ethernet II, ARP, IPv4, ICMP Ping
Áudio Intel High Definition Audio (HDA / ALC269/272) Driver
Controlador Intel HDA no barramento PCI (Device ID 0x8086:0x27D8). Configurar CORB (Command Out Ring Buffer) e RIRB (Response In Ring Buffer).
BAR0 MMIO: Registradores HDA, DMA Buffer Descriptors

Sistema de Arquivos, Syscalls & Shell do Usuário
0/4 concluídos
VFS (Virtual File System) & Driver FAT32 / Ext2 Core
Camada VFS com nós vnode/inode e suporte a leitura de partições MBR com sistema de arquivos FAT32 para leitura de binários e configurações.
APIs: vfs_open(), vfs_read(), vfs_write(), vfs_mount()
Instruções SYSCALL / SYSRET Rápidas de 64 bits Core
Configurar os MSRs IA32_STAR (0xC0000081), IA32_LSTAR (0xC0000082) e IA32_FMASK (0xC0000084) para troca instantânea de privilégios entre Ring 3 e Ring 0.
MSRs: LSTAR aponta para syscall_entrypoint, FMASK mascara RFLAGS.IF
Carregador de Executáveis ELF64 Core
Analisador de cabeçalhos ELF64 (ET_EXEC), mapeamento dos segmentos PT_LOAD na memória virtual da tarefa e salto para o e_entry.
Estruturas: Elf64_Ehdr, Elf64_Phdr, alocação sob demanda
Terminal Interativo & Shell Básico (Ring 3) Userland
Processo em espaço de usuário executando comandos básicos do sistema: help, sysinfo, lspci, meminfo, lscpu, cat, reboot.
Binário: /bin/sh compilado em C para Ring 3
